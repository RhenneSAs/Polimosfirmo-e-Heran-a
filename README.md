# Estudo de POO em Python

Projeto desenvolvido durante meus estudos de Python, com foco nos conceitos de Programação Orientada a Objetos (POO).

### Conceitos praticados
- Classes e objetos
- Herança simples
- Herança múltipla
- Polimorfismo
- Método `super()`
- `*args` e `**kwargs`
- MRO (Method Resolution Order)

### Objetivo
Praticar os conceitos de POO por meio de um exemplo de funcionários com diferentes modalidades de trabalho: presencial, remoto e híbrido.

Projeto criado para fins de estudo e aprendizado.
